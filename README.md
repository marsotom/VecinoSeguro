# VecinoSeguro (SOS360)

¡Hola! Bienvenido al repositorio de VecinoSeguro (también conocido como SOS360).

## Descripción del Proyecto

VecinoSeguro es un proyecto académico desarrollado como parte del curso APT122. El proyecto busca crear una solución para mejorar la seguridad en los vecindarios.

## Estructura del Repositorio

El repositorio está organizado en tres fases de desarrollo:

### Fase 1
- **Evidencias Grupales**: Documentación de evaluación y definición del proyecto
- **Evidencias Individuales**: Diarios de reflexión y autoevaluaciones

### Fase 2
- **Evidencias Grupales**: Guías de desarrollo y planillas de evaluación
- **Evidencias Proyecto**: Presentaciones y documentación del proyecto
- **Evidencias Individuales**: Reflexiones de la segunda fase

### Fase 3
- **Evidencia Grupal**: Presentación final y evaluación
- **Evidencia Individual**: Reflexión de la tercera fase

## Documentación

La documentación del proyecto incluye:
- Manual de Usuario
- Plan de Gestión de Riesgos
- Flujo de Caja
- Agile Roadmap
- Documentación de Sprints (Sprint 1, 2 y 3)
- Sprint Planning, Scrum Board, Burndown Charts
- Daily Meetings, Impediment Logs, Definition of Done
- Sprint Reviews y Retrospectivas

## Tecnologías

El proyecto utiliza metodología ágil Scrum para su desarrollo y está desplegado en:
- Google Play Store (aplicación móvil)
- Firebase (backend)
- Google Cloud
