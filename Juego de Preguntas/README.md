# Generador de Preguntas para Fiestas 🎉

Una aplicación web interactiva que genera preguntas de todo tipo para animar tus fiestas y reuniones.

## Características

- **6 Categorías de Preguntas:**
  - **Todas:** Mezcla de todas las categorías
  - **Verdad o Reto:** Preguntas para conocer secretos y experiencias
  - **Conocimiento:** Preguntas de cultura general y trivia
  - **Divertidas:** Preguntas creativas y entretenidas
  - **Profundas:** Preguntas para conversaciones significativas
  - **Hipotéticas:** Situaciones imaginarias para debatir

- **Más de 100 preguntas** distribuidas en diferentes categorías
- **Interfaz intuitiva y moderna** con diseño responsive
- **Generación aleatoria** de preguntas
- **Sin necesidad de instalación** - funciona directamente en el navegador

## Cómo Usar

1. Abre el archivo `index.html` en tu navegador web
2. Selecciona una categoría de preguntas (o deja "Todas" seleccionado)
3. Haz clic en "Generar Pregunta" o presiona Enter
4. ¡Disfruta de la pregunta con tus amigos!

## Personalización

Puedes agregar tus propias preguntas editando el archivo `preguntas.js`. Simplemente añade nuevas preguntas al array correspondiente siguiendo este formato:

```javascript
{ text: "Tu pregunta aquí", category: "Nombre de Categoría" }
```
